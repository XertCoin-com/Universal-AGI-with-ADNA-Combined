# Contributing

Thanks for contributing to Universal AGI with ADNA.

## Before You Start
- All usage and contributions are governed by this repository’s **LICENCE** file.
- By contributing, you confirm you have the right to contribute your work and agree to the repository terms.

## How We Work
- Small changes: open an Issue, then a PR referencing it.
- Larger changes: start with an RFC under `specs/rfcs/`.
- Conventional commits: `feat:`, `fix:`, `docs:`, `refactor:`, `chore:`

## Dev Setup
- Python 3.10+
- `pip install -r node/requirements.txt`
- Run `python node/devnet.py` to simulate proposer selection.

## PR Checklist
- [ ] Tests (if applicable)
- [ ] Docs updated
- [ ] Backwards compatibility considered
